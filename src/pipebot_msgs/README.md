# pipebot-msgs

This repo contains ROS2 messages for all Pipebots.

The `specifications` directory contains the messages specification documents defined by each theme.  Many of the messages used are provided by the [ROS2 common interfaces](https://github.com/ros2/common_interfaces) repo.

The `msgs`, `srv` and `action` directories contain Pipebot specific messages.

__NOTE__ The main branch cannot be pushed to directly.  When many people are working on the same branch, merge issues can occur, so using pull request branches reduces these problems.  Also it is good practice to get used to using pull requests as most open source project use this method of working.
