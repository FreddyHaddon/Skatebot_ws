# Chassis Controllers

This package is intended to contain more the following chassis controllers:

* `DiffDriveController` - This is a standard differential drive controller (a.k.a. skid steer controller) and will be implemented first.
* `FourWheelDriveController` - This is intended to improve on the `DiffDriveController` by independently controlling all 4 wheels of the SkateBot.

Each executable has its own launch file.
